This is Wine running in your browser on gex: 64-bit programs, and 32-bit ones through WoW64.

Drop files or folders from your computer onto the page: they are copied to this Desktop folder.
Open them from the file manager (press F5 there to see new files) or from cmd (cd %USERPROFILE%\Desktop).
